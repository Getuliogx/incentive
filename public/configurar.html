Preparar requisição do Incentive

1. No painel do Incentive, crie UMA meta de teste. Antes de confirmar, abra DevTools (F12) → Network. Use um nome raro e um valor raro para conseguirmos transformar a requisição em template.

2. Na requisição que EFETIVAMENTE cria a meta: botão direito → Copy → Copy as cURL (bash). Cole abaixo.

INCENTIVE_CREATE_CURL_B64

Copie o resultado para Render → Environment → INCENTIVE_CREATE_CURL_B64.
