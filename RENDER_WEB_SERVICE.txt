RENDER -> NEW -> WEB SERVICE

1. Conecte o repositorio do GitHub.
2. Runtime/Language: Node
3. Build Command: npm install
4. Start Command: npm start
5. Health Check Path: /health

ENVIRONMENT (somente estas duas sao obrigatorias):

TMDB_BEARER_TOKEN = seu token TMDB
INCENTIVE_BEARER_TOKEN = seu Bearer do Incentive

NAO criar PORT manualmente. O Render fornece PORT automaticamente.
NAO precisa PUBLIC_BASE_URL.
NAO precisa INCENTIVE_CREATE_CURL_B64.
NAO precisa GitHub Actions.
NAO precisa Blueprint/render.yaml.

Depois do deploy, abra:
https://SEU-SERVICO.onrender.com/

E no StreamElements use o conteudo de STREAM_ELEMENTS_COMMAND.txt.
